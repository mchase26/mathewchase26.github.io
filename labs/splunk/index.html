SIEM Network Topology

Project Overview

The objective of this lab was to deploy OPNsense as a virtual firewall between an internal LAN network and the internet-facing WAN interface.


This project simulated a small business network where security policies, traffic filtering, and network services must be properly configured and maintained.

Project Summary

Lessons Learned

  • Static IP configuration requires proper gateway assignment.
  • Configured WAN and LAN interfaces.
  • Implemented DHCP services.
  • Validated DNS resolution.
  • Firewall rules should follow least privilege for security.
  • Packet captures validate firewall behavior.
  • Created and tested firewall rules.
  • Troubleshot network connectivity issues.

Incident Report

Severity: Informational

Status: Resolved

Root Cause: Internal Linux server was unable to communicate with the firewall gateway.

Impact: Internal hosts could not access external resources until the issue was corrected.

Investigation: Verified IP addressing, subnet mask, and routing. Inspected ARP cache and observed failed neighbor resolution. Determined the firewall LAN interface was assigned to the incorrect virtual adapter.

Resolution: Corrected the OPNsense interface assignment, restored ARP communication, and validated connectivity using ICMP, HTTP, and packet captures.

Verification: Confirmed successful host-to-host communication, Internet access, Apache web service availability, and firewall log entries by using Packet Capture Toools and Ping.
